# 나의 기록 PWA

## 포함 기능
- 한달기록 / 디깅기록 / 버킷리스트 / 셀프 Q&A / 보관함
- Firebase 이메일 로그인
- 모바일·PC·iPad 실시간 동기화
- **전체 동기화**: 로컬 + 클라우드 값을 항목별 수정시간으로 병합 후 클라우드에 확정 저장
- 빈 로컬 데이터가 기존 클라우드 기록 전체를 덮어쓰지 않도록 필드 단위 병합
- 오프라인 localStorage 저장 + 온라인 복귀 시 재동기화
- PWA 설치(manifest + service worker)
- JSON 백업. 백업 버튼을 Shift+클릭(PC) 또는 길게/보조 클릭하면 복원 파일 선택 가능

## GitHub Pages
이 폴더의 파일을 저장소 루트에 업로드한 뒤 Pages를 켜면 됩니다.

## Firebase
기존 `maeum-jogak2` 프로젝트 설정을 사용합니다. Authentication에서 이메일/비밀번호 로그인이 활성화되어 있어야 합니다.
`firestore.rules`는 사용자 UID 아래 데이터만 본인이 읽고/쓸 수 있도록 하는 규칙 예시입니다. 현재 프로젝트에 더 세밀한 기존 규칙이 있다면 전체 규칙을 덮어쓰지 말고 해당 경로 규칙만 합쳐주세요.

## 데이터 경로
`users/{uid}/record_archive_app/state`

## 동기화 방식
각 입력값/별표/완료 체크는 각각 `{value, updatedAt, deviceId}` 성격의 레코드로 저장됩니다. 전체 동기화는 로컬과 클라우드에서 각 항목의 더 최신 값을 선택하므로, 다른 기기에서 작성한 서로 다른 항목들이 함께 보존됩니다.
